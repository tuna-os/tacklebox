# Tacklebox v0.1.0

This is the first supported Tacklebox release. Consumers can pin the CLI to
this version and avoid the mutable `main` branch.

## Artifacts

- Static Linux binaries: `tacklebox-linux-amd64` and
  `tacklebox-linux-arm64`.
- SHA-256 checksum files for both binaries.
- Multi-architecture container image:
  `ghcr.io/tuna-os/tacklebox:v0.1.0` (also tagged `0.1.0`).

Verify and install a binary with:

```sh
sha256sum --check tacklebox-linux-amd64.sha256
sudo install -m 0755 tacklebox-linux-amd64 /usr/local/bin/tacklebox
```

## Supported baseline

- Linux hosts on AMD64 and ARM64.
- Disk images and physical block devices built from bootc container images.
- UEFI live ISO creation on AMD64, including per-environment, combined dedup,
  and delta layouts.
- The `build`, `update`, `update-all`, `add`, `remove`, `status`, `verify`,
  `recipe-gen`, and `customize-live` commands.

Recipes accepted by v0.1.0 form the initial compatibility baseline. Tacklebox
remains pre-1.0: later v0.x releases may make incompatible changes when they
are called out in their release notes. Pin this tag or the published container
digest for reproducible automation.

## Known limitations

- ARM64 live ISO assembly is not yet supported. The ARM64 binary supports the
  Linux host workflows that do not need an ARM64 ISO boot chain.
- `add` and `remove` mutate block targets only; rebuild an ISO to change its
  environments.
- Distinct block-target images can resolve to the same OSTree commit during
  serial `bootc install`. `tacklebox verify` detects this condition. This
  defect does not affect ISO targets.
- Persistent storage has no per-environment quota, garbage collection, or
  recipe-migration policy yet.

Media creation still needs the host tools listed in the
[README](https://github.com/tuna-os/tacklebox/blob/v0.1.0/README.md).

## Rollback

Binary consumers can reinstall an earlier release asset. Container consumers
should pin the previous version, digest, or `sha-<commit>` tag. If a bad image
moves `latest`, follow the
[container rollback runbook](https://github.com/tuna-os/tacklebox/blob/main/runbooks/rollback-a-bad-tacklebox-image.md).
